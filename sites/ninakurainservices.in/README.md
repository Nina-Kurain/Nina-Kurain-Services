# 🌐 ninakurainservices.in (Public Domain & Showcase)

This folder defines all pages, assets, and routes belonging to the **main public domain** (`https://ninakurainservices.in`).

---

## 📁 Public Domain Scope & Responsibilities

1. **Public Landing & Showcase**:
   - `app/page.tsx` & `app/site-client.tsx` (Official homepage, hero, bio, seductive teaser marquee)
   - `app/lookbook/`, `app/gallery/`, `app/photos/` (High-resolution public editorial previews)
   - `app/memberships/` & `app/pricing/` (Public membership tier catalog with Razorpay checkout)

2. **Official App Downloads**:
   - `public/downloads/NinaKurain.apk` (Official Android APK with FLAG_SECURE & custom icon)
   - `public/downloads/NinaKurain.ipa` (Official iOS App Package)
   - `public/downloads/manifest.plist` (Apple OTA installation manifest)

3. **SEO & Discoverability**:
   - `app/sitemap.xml`, `app/image-sitemap.xml`, `public/robots.txt`
   - Pinterest site verification & Google AdSense integration

4. **Legal & Compliance**:
   - `app/terms-and-conditions/`, `app/privacy-policy/`, `app/content-removal/`
